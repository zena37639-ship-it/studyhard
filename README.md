# StudyHard - Интерактивное обучающее приложение

## Описание
StudyHard - это интеллектуальное приложение для изучения различных предметов. Оно поддерживает объяснение тем и проверку знаний через тесты.

## Функциональность

### 1. Загрузка темы
- Выбор предмета: Английский, Математика, Русский и т.д.
- Введение названия темы для изучения

### 2. Объяснение темы
- Подробное объяснение загруженной темы
- Примеры и иллюстрации

### 3. Тестирование знаний
- 10 вопросов по изученной теме
- Система проверки ответов
- **Система ошибок**: если допущено 2 и более ошибки, все вопросы не засчитываются, выдается новый набор из 10 вопросов

### 4. Оценка эссе (опционально)
При запросе оценки эссе проверяется:
- **Грамматика** - корректность использования грамматических конструкций
- **Вокабуляр** - минимум B1 уровень для английского и русского
- **Структура текста** - логичность построения, наличие введения, основной части, заключения
- **Достижение целей эссе** - соответствие теме и выполнение поставленных задач

## Использование
1. Запустите приложение
2. Выберите предмет
3. Введите тему для изучения
4. Прочитайте объяснение
5. Ответьте на 10 вопросов
6. Получите результаты

## Требования
- Python 3.8+
- Доступ к API для обработки текста

## Установка
```bash
pip install -r requirements.txt
python main.py
```
